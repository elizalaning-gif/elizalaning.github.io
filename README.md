## 🌿 About This Project
 
This site is built as a **single-page static website** hosted on GitHub Pages. It provides a comprehensive, authoritative guide on dormant pruning including:
 
- What dormant pruning is and why it matters
- Best time to perform dormant pruning
- Step-by-step techniques for trees, shrubs, roses, and fruit trees
- Tools required and how to use them safely
- Common mistakes to avoid
- FAQ section optimized for AI Overview / Featured Snippets
